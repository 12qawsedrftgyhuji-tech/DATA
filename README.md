#project name : DATA(Digital Accessiblity & Technology for All)

##주요 기능
<로그인>
-**최첨단 구글 로그인 기능을 구현**
-**슈퍼 울트라급 게스트 로그인 가능**
-**개레전드급 네이버 로그인 포함!!**
-**울트라 레전드급 카톡 로그인 구현!!**
<게시글(홈)>
-**웹뷰 기술에서 착안한 html문법을 자동으로 넣어줘서 글과 이미지를 동시에 볼 수 있게 하는 기능**
-**관리자 계정으로 로그인했을 때만 게시글을 올리거나 수정할 수 있거나, 삭제할 수 있는 버튼이 보이도록 하는 기능**
-**수정할 때는 원래 게시글 내용을 그대로 가져와서 기존 게시글 내용에서 바로 수정할 수 있도록 하는 기능**
-**삭제할 때는 한번더 삭제할 것인지 물어봐서 실수로 삭제를 눌러도 다시 고민할 수 있도록 하는 기능**
<AI 탭>
-**AI기능 선택 창(오프라인/온라인 AI) 띄워주기**
<AI 탭-오프라인 AI>
-**카메라를 이용하여 오프라인에서 AI와 마이크로 서로 대화할 수 있는 기능**
-**STT, TTS, OCR 기술을 이용하여 온디바이스AI로 최대한 작업한다음 LLM으로 정보를 넘겨주어 토큰 절약 및 개인정보 보호를 동시에 수행할 수 있게 함.**
-**TTS 말하기 속도를 직접 조절할 수 있게 설정함.**
-**카메라 접근 허용을 눌러야 카메라가 작동함.**
-**최근 대화 20개를 함께 불러올 수 있도록 하고, AI가 사용자의 대화 context를 이해할 수 있도록 함.**
